name: document-channel
description: "Define or update a YouTube channel's identity, visual system, thumbnail guide, or production workflow."
---

Open the relevant [channel configuration](../../../canal/00-config/) files. Use the opening comment as a template and the visible text as the current decisions.

- For a new channel, use [channel-identity.md](../../../canal/00-config/channel-identity.md) to capture the audience, promise, and tone. Complete other documents as the work calls for them.
- When revising a practice, find its source document and preserve decisions the user has already made. Identify open decisions and add agreed changes to the visible text when the user asks for updates.
- For a [visual-system.md](../../../canal/00-config/visual-system.md) review, identify what the viewer needs to understand and which rule affects the scene. Propose a concrete change, a test scene, and what to compare for clarity, legibility, or continuity. Record a production-specific test in its brief and an adopted rule in the channel's visual system.
- Consult the [scriptwriting guide](../../../canal/00-config/scriptwriting-guide.md), [thumbnail guide](../../../canal/00-config/thumbnail-guide.md), or [production workflow](../../../canal/00-config/production-workflow.md) if the change affects them. Link to the rule where other documents need it.

Report the agreed decisions, updated files, and open questions.
